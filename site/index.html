How it works

Your agent starts. Qeuli notices.

It hears the start

Hooks for Claude Code, a notify line for Codex, or qeuli run -- any command. It can also watch a process, like a training job or a build.

It fills the gap

A nudge that fits the wait: water, an eye rest, a parked idea, a stretch, something you saved to read.

It tells you when it's done

A desktop notification when the agent finishes, plus a plain-English recap of what it did while you were away.

Privacy and setup

Yours, on your machine.

  • Nothing is hosted. No account, no telemetry, no server of ours.
  • Labels, not contents. It keeps tool names and short labels, never file contents, full paths, full commands or prompts.
  • One file of data. Written atomically, with a rolling backup.
  • Closed to websites. The background service listens on loopback only and rejects requests that do not come from the app or the CLI.
  1. Download and run the installer. Open Qeuli from the Start menu; it lives in the tray.
  2. Connect Claude Code (optional, one command):
    qeuli install claude
  3. Or wrap any command:
    qeuli run -- npm test

The installer is not code-signed yet, so Windows SmartScreen may show "unknown publisher". Choose More info, then Run anyway. Each release lists a SHA-256 checksum so you can verify the file.
